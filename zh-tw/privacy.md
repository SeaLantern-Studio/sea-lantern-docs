歡迎使用 SeaLantern（海晶燈）！本協議是您與 SeaLantern 開發團隊（以下簡稱「我們」、「團隊」）之間關於使用 SeaLantern 軟體及相關服務（以下簡稱「本軟體」）的法律協議。我們依據《中華人民共和國網路安全法》、《中華人民共和國個人資訊保護法》等法律法規制定本協議，以保障您的知情權。

請您在使用本軟體前仔細閱讀並充分理解本協議的全部內容。如果您不同意本協議的任何條款，請立即停止使用本軟體。

## 一、總則

**1.1 軟體性質**

本軟體是一款開源的 Minecraft 伺服器管理工具，原始碼遵循 AGPLv3 協議公開。

**1.2 透明原則**

我們承諾以透明、誠實的方式對待每一位使用者。本協議將如實告知您關於資訊處理的實際情況。

**1.3 協議接受**

如您使用本軟體，即視為您已閱讀並同意接受本協議。

## 二、目前的資訊收集情況

截至本協議生效之日，SeaLantern 不包含遙測、廣告追蹤或使用統計功能。具體說明如下：

**2.1 不自動收集資訊**

本軟體不會主動向專案團隊上傳裝置資訊、使用日誌、崩潰報告或其他可識別個人身份的資訊。伺服器設定、存檔和執行日誌預設儲存在您的本機裝置。

**2.2 不請求敏感權限**

本軟體不會向您的作業系統請求通訊錄、簡訊、位置等敏感權限。其功能僅限於管理本機 Minecraft 伺服器及相關的檔案操作。

**2.3 使用者主動提供的資訊**

當您透過 GitHub Issues、電子郵件或社群聯絡我們時，您可能主動提供您的聯絡方式（如 GitHub 使用者名稱、電子郵件）以及回饋內容。這些資訊僅用於與您溝通，且由您自願提供，不屬於軟體自動收集範疇。

**2.4 按需連網功能**

當您主動使用核心下載、更新檢查、插件市場或 P2P 連線等功能時，軟體會連接相應的第三方服務或連線節點。完成請求所需的網路資訊（例如 IP 位址和請求內容）可能由服務提供者依其隱私政策處理，專案團隊不會為遙測目的另行收集這些資訊。

## 三、未來可能的變更

**3.1 變更告知**

隨著軟體功能的發展，我們未來可能會增加某些資訊收集功能（例如：匿名崩潰報告、功能使用統計等），以改進軟體品質。任何此類變更均會：

- 提前透過 GitHub 公告或社群通知等方式明確告知；
- 在隱私協議中詳細說明收集的資訊類型、目的及使用方式；
- 在法律要求時，徵得您的明確同意。

**3.2 拒絕權利**

您有權在任何時候拒絕未來的資訊收集（例如選擇不開啟崩潰報告功能）。

## 四、資訊共享與揭露

**4.1 目前情況**

專案團隊不會出售或主動共享軟體使用資料。按需連網功能所連接的第三方服務會處理完成請求所需的資訊，具體規則以對應服務的隱私政策為準。

**4.2 未來例外情形**

未來如增加資訊收集功能，我們承諾不會出售、出租或以其他方式向第三方提供您的個人資訊，但以下情形除外：

- 獲得您的明確同意；
- 根據法律法規、法律程序或政府機關的要求必須提供；
- 為維護我們、其他使用者或公眾的合法權益所必要。

## 五、使用者權利

根據《個人資訊保護法》，您對您的個人資訊享有查詢、更正、刪除、撤回同意等權利。目前因我們不收集資訊，暫無需行使這些權利。未來如有資訊收集，我們將提供便捷的管道供您行使權利。

## 六、資訊儲存與安全

**6.1 本機儲存**

本軟體目前所有資料均儲存於您的本機裝置，不涉及雲端儲存。

**6.2 未來儲存規則**

未來如有資訊收集，對於中華人民共和國境內使用者的個人資訊，我們將依法儲存於中華人民共和國境內。如需向境外傳輸，我們將另行告知並徵得您的單獨同意。

## 七、未成年人保護

**7.1 目前情況**

本軟體面向所有使用者，包括未成年人。由於目前不收集資訊，未成年人可以放心使用。

**7.2 未來保護措施**

如未來增加資訊收集功能，我們將嚴格遵守《未成年人保護法》，對 14 周歲以下使用者的個人資訊給予特殊保護。

**8.1 軟體現狀**

本軟體按「現狀」提供，不附帶任何明示或暗示的保證。我們不保證軟體完全無錯誤、不間斷或滿足您的特定需求。

**8.2 使用風險**

您理解並同意，使用本軟體所涉及的操作（如啟動 Minecraft 伺服器、安裝插件）均存在風險，包括但不限於資料遺失、伺服器崩潰等。我們將盡最大努力降低風險，但不對任何直接或間接損失承擔責任。此限制不適用於因我們的故意或重大過失造成的損失。

**8.3 第三方內容**

本軟體可能包含指向第三方網站或服務的連結，我們不對此類第三方的內容、隱私政策或行為負責。
